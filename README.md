# Futbol 360 - UEFA Champions League 2024-25

Aplicacion en Next.js + TypeScript con un diseño inspirado en la interfaz de la Champions League. Los datos se basan en resultados y clasificacion reales de la temporada 2024-25.

## Scripts

- npm run dev
- npm run build
- npm run start
- npm run lint

## Paginas

- / (inicio)
- /teams (equipos)
- /teams/[id] (detalle de equipo)
- /matches (partidos)
- /results (resultados)
- /standings (clasificacion)
